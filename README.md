AASTU Student Club and Event Management System

A console-based C++ application developed for managing student clubs, memberships, and campus events at Addis Ababa Science and Technology University.
The system is designed to replace paper-based club management with a digital and organized solution using advanced C++ programming concepts such as structures, STL, modular programming, and file handling.

📌 Project Overview

Many student clubs at AASTU still rely on manual paper-based systems for:

Student registration
Event organization
Attendance tracking
Report generation
Membership management

This creates problems such as:

Data inconsistency
Risk of losing records
Difficult file organization
Time-consuming workflows
Increased paper consumption

The AASTU Student Club and Event Management System solves these challenges by automating club operations through a modular C++ console application.

🎯 Main Objectives
Reduce paper usage across campus
Improve club organization and management
Increase student satisfaction
Automate repetitive administrative tasks
Store data securely and efficiently
Prepare students for relational database concepts and SQL systems
